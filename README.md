# AiMate - Your Smart AI Companion

AiMate is a modern, cross-platform Progressive Web Application (PWA) that serves as an all-in-one AI assistant. By integrating advanced AI APIs (like OpenAI/Deepseek), it provides a seamless chat experience through multiple interfaces, including a web app, voice assistant, and a Telegram bot.

## ✨ Features

- **Progressive Web App (PWA):** Installable on mobile devices with an app-like UI.
- **AI Chat & Integration:** Connects securely to AI models via a backend proxy.
- **Voice Assistant:** Built-in Speech-to-Text and Text-to-Speech capabilities.
- **Telegram Bot Sync:** Chat with the same AI assistant via Telegram using a unified backend.
- **Secure Backend:** API keys and logic are safely handled on the server side.

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS (Mobile-first UI), Web Speech API.
- **Backend:** PHP, cURL/Guzzle (for external APIs).
- **Database & Cache:** MySQL, Redis (for session management & rate limiting).
